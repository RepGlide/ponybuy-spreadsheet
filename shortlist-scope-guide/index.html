Shortlist Scope Guide

Build a bounded research shortlist around one category and a clear use.

A short list is easier to check

A shortlist works because it is short. Decide the scope before you browse, then let every candidate earn a slot within that scope — not widen it.

Pick one category

Fix the category first. A shortlist that spans many categories is a feed, not a shortlist.

State the use

Write down what the item is for. The use is the test every candidate is measured against.

List necessary options

Name the color, size, version, and quantity you need. These keep the scope from drifting.

Do not expand from heat or rank

Popularity and ranking are not reasons to widen the scope. If a hot item is outside the category or use, it stays outside.

✓Confirmation boundary: scope is decided before browsing, not expanded by a label.
Edit noteIf a candidate does not fit the category, the use, or the necessary options, it is out of scope — however popular it is.

A worked scope

  1. Category: sneakers.
  2. Use: daily walking.
  3. Options: size 42, single pair.
  4. Result: only sneakers that fit the use and options enter the list.

Editing example — not a recommendation, ranking, verified list, or saved shortlist.
